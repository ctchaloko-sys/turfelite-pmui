# Installation de TURFELITE-PMU

Bienvenue dans le guide d'installation de votre plateforme web. Suivez ces étapes simples.

## 1. Créer le projet Supabase
1. Allez sur [Supabase.com](https://supabase.com) et créez un compte / connectez-vous.
2. Créez un nouveau projet (New Project). Notez le mot de passe de la base de données.
3. Allez dans `Project Settings` > `API`. Vous y trouverez :
   - L'URL de votre projet (`https://xyz.supabase.co`)
   - Votre clé `anon` public.

## 2. Configurer le code source
1. Ouvrez le fichier `app.js`.
2. Ligne 10, remplacez `https://VOTRE_PROJET.supabase.co` par votre URL Supabase.
3. Ligne 11, remplacez `VOTRE_CLE_ANON` par votre vraie clé publique.

## 3. Préparer la Base de Données
1. Dans votre interface Supabase, allez dans l'onglet **SQL Editor**.
2. Cliquez sur `New query`.
3. Copiez TOUT le contenu du fichier `supabase.sql` fourni et collez-le ici.
4. Cliquez sur le bouton vert **RUN** en bas à droite.
   *(Cela créera toutes les tables, la sécurité et ajoutera les données de démonstration).*

## 4. Devenir Administrateur
1. Allez sur le site en ligne (ou en local) et créez-vous un compte classiquement (S'inscrire).
2. Retournez dans Supabase > SQL Editor et exécutez la commande suivante :
   `UPDATE profiles SET role = 'admin' WHERE email = 'votre-email@gmail.com';`
3. Rafraîchissez votre site. Vous avez maintenant accès à `votresite.com/#/admin`.

## 5. Mettre le site en ligne
Hébergez simplement les fichiers `index.html`, `style.css`, `app.js`, et les images `harness-racing.jpg` / `galop-racing.jpg` sur un service gratuit comme Vercel, Netlify ou GitHub Pages. Aucune compilation n'est requise.

## Notes sur les Emails de Contact (Optionnel)
Le fichier `supabase/functions/send-contact/index.ts` nécessite l'utilisation de Supabase CLI et d'un compte Resend.com pour envoyer les emails. Si cette fonction n'est pas déployée, les messages seront quand même sauvegardés dans la table `messages` de votre base de données, lisible depuis l'interface Supabase ou votre panneau Admin.
